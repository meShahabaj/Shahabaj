## ▶️ **How to Run the Project Locally**

### **Clone the Repository**

```bash
git clone https://github.com/meShahabaj/Shahabaj.git
cd Shahabaj
```

---

## 💻 **Run Frontend**

```bash
cd Frontend
npm install
npm start
```

Frontend will run at:

```
http://localhost:3000
```

---

## 🖥️ **Run Backend**

```bash
cd Backend
pip install -r requirements.txt    # or uv sync
python app.py
```

Backend will run at:

```
http://localhost:5000
```
